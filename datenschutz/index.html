Datenschutzerklärung

Der Schutz Ihrer persönlichen Daten ist uns ein besonderes Anliegen. Wir verarbeiten Ihre Daten daher ausschließlich auf Grundlage der gesetzlichen Bestimmungen (DSGVO, TKG 2003).

1. Kontaktformular (EmailJS)

Wenn Sie per Formular auf der Website Kontakt mit uns aufnehmen, werden Ihre angegebenen Daten zwecks Bearbeitung der Anfrage und für den Fall von Anschlussfragen bei uns gespeichert. Diese Daten geben wir nicht ohne Ihre Einwilligung weiter. Die Verarbeitung erfolgt über den Dienst EmailJS.

2. KI-Chatbot

Auf dieser Website wird ein interaktiver Chatbot eingesetzt. Zur Bereitstellung dieser Funktion gelten folgende Bedingungen:

  • Verarbeitung: Eingegebene Chat-Texte werden an unsere Server-Infrastruktur (Render.com) und zur Generierung der Antwort an das KI-Modell von Groq (USA) übermittelt.
  • Local Storage: Zur Speicherung Ihres Chatverlaufs innerhalb einer Sitzung wird die "LocalStorage"-Technik Ihres Browsers verwendet. Diese Daten verbleiben auf Ihrem Endgerät und werden von uns nicht auf eigenen Servern dauerhaft gespeichert.
  • Anonymität: Bitte geben Sie keine sensiblen persönlichen Daten (Namen, Adressen, Passwörter) in den Chat ein.

3. Web-Hosting

Der Host dieser Website (z. B. GitHub Pages / Render) erhebt automatisch Daten über Website-Zugriffe (Server-Logfiles), darunter Ihre IP-Adresse. Dies ist technisch notwendig, um die Sicherheit und Stabilität der Website zu gewährleisten.

4. Ihre Rechte

Ihnen stehen grundsätzlich die Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung, Datenübertragbarkeit, Widerruf und Widerspruch zu. Wenn Sie glauben, dass die Verarbeitung Ihrer Daten gegen das Datenschutzrecht verstößt, können Sie sich bei der Aufsichtsbehörde beschweren (In Österreich: Datenschutzbehörde).
